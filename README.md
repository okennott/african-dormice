# African-dormice (Genus *Graphiurus*)

This data repository hosts the raw data, analysis scripts, and alignments (cytochrome b alignments and UCE sample-specific contigs), and trees in the manuscript 'Diversification and biogeographic history of African dormice (genus *Graphiurus*) revealed by ultraconserved elements and mitochondrial data'

------------------------------------------------------------------------

**"alignments_UCE_n_CYTB.zip"** is a zip file containing three alignment files used in the study:

1)  "\_Gliridae_CYTB_aln.fas": the redundancy-filtered cytochrome b alignment of the family Gliridae.

2)  "\_Graphiurus_CYTB_aln.fas": the redundancy-filtered cytochrome b alignment of the genus Graphiurus, including newly sequenced samples and those retrieved from GenBank, spanning all available grilid representatives.

3)  "\_UCE_concatenated_aln.nex": the concatenated alignment of the ultraconserved elements (UCE) dataset in nexus format with a block defining the partitions occupied by each constituent locus at the end of the file.
